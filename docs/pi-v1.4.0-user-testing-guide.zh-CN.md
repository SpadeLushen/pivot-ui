# pi 1.4.0：用户界面验收指南

不需要写代码、安装测试工具或执行命令。先做下面的日常操作检查；正常情况下约 10 分钟。对话会使用所选模型的额度，建议选一个成本较低的模型，在单独的测试会话里操作，不上传敏感文件。

## 开始前：先运行新版服务

此前已完成代码和构建，但没有停止或重启现有服务。请先由负责启动 Pivot 的人确认服务已加载这次新版构建；只刷新浏览器不能替代后端更新。

随后刷新页面，点击“新会话”。欢迎页应显示 pi 1.4.0；如果仍是 1.3.0，先不要继续验收。

## 1. 能正常聊天

**操作**：新建会话，发送：

> 请只回复：测试收到。不要使用工具。

**应该看到**：回复正常显示，结束后可以继续输入，不一直显示正在生成，也没有重复回复。

## 2. 工具能正常执行

**操作**：在一个可用于测试的工作区发送：

> 请用只读工具列出当前工作区顶层的文件名。不要读取文件内容，也不要创建、修改或删除任何文件。

**应该看到**：出现工具调用及结果，随后模型正常结束；可以展开查看工具输出，界面不一直卡在执行中。

若出现确认询问，按下一节检查；若你的环境自动允许只读操作，没有询问是正常的。

## 3. 遇到询问时，检查新的底部面板

在平时会触发确认、选择或输入的扩展操作中检查。不必安装测试插件，更不要为触发确认尝试删除或覆盖文件。没有遇到询问，就把此项记为“未测”。

**应该看到**：

- 普通输入区域收起，询问显示在会话底部，横向展开。
- 没有遮罩；上面的聊天记录仍能滚动、选择和复制。
- 点击“取消”不会被当成同意；确实同意的操作才点击“确认”。
- 如果出现输入框，能正常输入中文；选择输入法候选词时的 Enter 不应提前提交。
- 所有询问处理完后，普通输入区恢复；之前未发送的草稿和附件仍在。
- 如果连续遇到多个问题，处理当前问题后能回到前一个未完成的问题。

手机上再试一次：弹出键盘后，输入内容及确认/取消按钮应能看到或滚动到，不能被键盘挡住而无法操作。

## 4. 能停止，也能继续发送

**操作**：发送：

> 请分 20 点介绍 Git 分支的常见用法，每点写两句话。

看到回复开始生成后，点击“停止生成”。然后发送：

> 请只回复：可以继续。

**应该看到**：前一次生成停止，界面不一直卡住；下一条消息能正常回复。如果恰好正在询问你，底部也应保留停止入口。

## 5. 刷新后，会话能恢复

**操作**：重新打开这个测试会话，刷新网页。

**应该看到**：之前的消息和工具结果仍在，没有重复气泡，可以继续聊天。

**选做**：在一次较长回复还在生成时刷新。应恢复运行状态并继续显示结果，最终正常结束，而不是永久显示“正在生成”。不需要故意断网。

## 6. 中文完整历史能正常打开

**操作**：发送：

```text
请按 Markdown 输出下面这句话，不要使用代码块：
这是**加粗**，这是*斜体*。
```

回复结束后，点击会话顶部的“完整历史”，打开新页面。

**应该看到**：会话内容正常打开，中文标点旁的粗体、斜体正确显示，不是一串原始星号；较长会话的历史树也能点击，不白屏或卡死。

## 选做：只测你本来就在用的功能

### 长会话压缩

仅在内容较多、可随时丢弃的测试会话里发送：

> /compact 重点保留用户要求、关键结论和未完成事项

压缩结束后，问一个之前讨论过的关键问题。应能继续对话，重要约定没有明显丢失。如果提示暂时无需压缩，换一份更长的测试会话或记为未测，不必反复发送。压缩也会消耗模型额度。

### MCP 和模型选择

如果你原来使用 MCP，打开 Tools，确认已有服务器仍能看到，日常只读查询仍可用。不要为测试更改凭据、开关生产服务器或切换生产工作区的 Packs。

如果你使用 MiniMax-M3.1-Flash，思考选项不应提供 off；如果使用 xAI 的 Grok 4.3/4.5，应能看到 xhigh。没用这些 Provider 就跳过，不需要新开账户或新增密钥。

### 繁忙时的工具等待

日常多会话并行时，如果 codemode 工具先显示进行中、稍后才出结果，可能是在等待空闲名额。重点观察最终能结束、能停止、失败后能继续发送，不必专门制造三个长任务来测上限。

worker 精确并发、60 秒边界、BOM 文件格式和图片请求格式，由开发者负责验证，不需要你手工构造。

## 怎样反馈问题

逐项写“通过 / 有问题 / 未测”即可；没有用到的功能无需强行测试。

遇到问题时，给我这些信息就够了：

```text
第几项：例如第 3 项，底部询问
我做了什么：点击取消后又切回这个会话
实际发生：输入区没有恢复，仍显示旧问题
设备：电脑/手机，浏览器名称
出现频率：每次/偶尔
截图：有则附上，遮住私人内容
```

不要发送 API key、登录信息或含敏感内容的完整会话。你不需要自行分析日志或判断 SDK 哪里出错，我会根据现象继续定位。

完成前六项，能够确认主要日常使用路径；“未测”项目单独保留，不必为了完成清单增加付费调用。
